## 本次源码

- 新增独立“借票策略”页，来源与目标分别支持按账号或动态分组选择。
- 来源优先，目标候选与已有选择自动排除来源；目标分组按实时成员扣除来源，保留账号与分组上限及资格校验。
- SSE 探针完整终态及时结束、有效结果优先复用、自动准备跳过健康目标，失败不阻断后续目标。
- 动态成员变化使旧自动任务与 WS 借票连接失效；事务复核成员，单改调度不重写账号映射和 WS 配置。
- 旧账号模式保持兼容，失效策略仍可修改或关闭；不执行线上数据库写入、迁移或部署。
