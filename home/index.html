01

特别提示：服务性质与范围

iCode API 是一个通用 API 中转与接口集成测试站点，仅用于合法合规的接口转发、协议适配、集成测试与能力体验。 本站可能接入多类第三方 API 能力，包括但不限于通用 Web API、开发调试接口、自动化测试接口及 AI 能力接口。

对于其中可能涉及生成文本、图片、音频、视频等内容的 AI 能力接口，本站不开发、训练或拥有任何底层人工智能模型。 根据中国现行生成式人工智能服务监管要求，利用生成式 AI 技术向中国境内公众提供生成内容服务， 包括通过可编程接口等方式提供服务，可能适用安全评估、算法备案、内容治理、投诉举报、违法处置等合规要求。 本站当前不面向中国境内公众提供服务。

  • 所有接入接口均应来自公开、合法、可被第三方通过 API 方式调用的服务。
  • 本站不接入通过逆向工程、破解、盗用账号等非法手段获取的接口或服务。
  • 本站仅收取技术传输与平台维护的基础成本费用，费用对应技术服务而非第三方内容或能力本身。
  • 本网站已关闭新用户注册，如有特殊情况，请联系管理员。
