# 客户端接入

客户端接入只需要三类信息：

- Base URL：你的 Sub2API 站点地址
- API Key：用户在前端生成的 `sk-...`
- 端点：由客户端协议决定，例如 `/v1/messages`、`/v1/responses`、`/v1beta`

下面示例使用：

```text
SUB2API_BASE_URL=https://api.example.com
SUB2API_API_KEY=sk-xxxx
```

请替换成自己的域名和 Key。

## Claude Code

Anthropic 或 Antigravity Claude 分组可使用 Claude Code 方式接入。

Linux/macOS：

```bash
export ANTHROPIC_BASE_URL="https://api.example.com"
export ANTHROPIC_AUTH_TOKEN="sk-xxxx"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL="https://api.example.com"
$env:ANTHROPIC_AUTH_TOKEN="sk-xxxx"
$env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
```

如果是 Antigravity Claude 分组，地址改为：

```text
https://api.example.com/antigravity
```

## Gemini CLI

Gemini 分组可使用 Gemini v1beta 兼容入口。

Linux/macOS：

```bash
export GOOGLE_GEMINI_BASE_URL="https://api.example.com"
export GEMINI_API_KEY="sk-xxxx"
export GEMINI_MODEL="gemini-2.0-flash"
```

PowerShell：

```powershell
$env:GOOGLE_GEMINI_BASE_URL="https://api.example.com"
$env:GEMINI_API_KEY="sk-xxxx"
$env:GEMINI_MODEL="gemini-2.0-flash"
```

如果客户端要求填写完整 Gemini API 根路径，可使用：

```text
https://api.example.com/v1beta
```

Antigravity Gemini 使用：

```text
https://api.example.com/antigravity/v1beta
```

## Codex CLI

OpenAI 分组可使用 Codex CLI 配置。前端“使用密钥”弹窗会生成 `config.toml` 和 `auth.json`。

示例 `~/.codex/config.toml`：

```toml
model_provider = "sub2api"
model = "gpt-5.4"
review_model = "gpt-5.4"
model_reasoning_effort = "xhigh"
disable_response_storage = true
network_access = "enabled"
windows_wsl_setup_acknowledged = true
model_context_window = 1000000
model_auto_compact_token_limit = 900000

[model_providers.sub2api]
name = "sub2api"
base_url = "https://api.example.com"
wire_api = "responses"
requires_openai_auth = true
```

示例 `~/.codex/auth.json`：

```json
{
  "OPENAI_API_KEY": "sk-xxxx"
}
```

如果要使用前端提供的 WebSocket 配置，`config.toml` 会额外包含：

```toml
[model_providers.sub2api]
supports_websockets = true

[features]
responses_websockets_v2 = true
```

以页面生成内容为准。

## OpenAI 兼容 curl

Chat Completions：

```bash
curl "https://api.example.com/v1/chat/completions" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [
      {"role": "user", "content": "hello"}
    ]
  }'
```

Responses：

```bash
curl "https://api.example.com/v1/responses" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "input": "hello"
  }'
```

## Anthropic 兼容 curl

```bash
curl "https://api.example.com/v1/messages" \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-6",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "hello"}
    ]
  }'
```

## Gemini 兼容 curl

```bash
curl "https://api.example.com/v1beta/models/gemini-2.0-flash:generateContent" \
  -H "x-goog-api-key: sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "parts": [
          {"text": "hello"}
        ]
      }
    ]
  }'
```

如果客户端不支持 `x-goog-api-key`，可优先尝试 `Authorization: Bearer sk-xxxx`；最终以当前客户端和网关认证中间件支持为准。

## OpenCode

用户端“使用密钥”弹窗会按平台生成 OpenCode 示例。通用结构如下：

```json
{
  "provider": {
    "openai": {
      "options": {
        "baseURL": "https://api.example.com/v1",
        "apiKey": "sk-xxxx"
      }
    }
  },
  "$schema": "https://opencode.ai/config.json"
}
```

Anthropic 平台使用 `/v1`，Gemini 平台使用 `/v1beta`，Antigravity 按 Claude 或 Gemini 分别使用 `/antigravity/v1` 和 `/antigravity/v1beta`。
