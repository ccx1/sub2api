# 监控、日志与运维

本页整理 Sub2API 当前仓库已有的运行、日志、监控和构建脚本。

## Docker 日志

本地目录版：

```bash
docker compose -f docker-compose.local.yml ps
docker compose -f docker-compose.local.yml logs -f sub2api
docker compose -f docker-compose.local.yml restart sub2api
```

命名卷版：

```bash
docker compose ps
docker compose logs -f sub2api
docker compose restart sub2api
```

Docker 中 `/app/data` 是默认数据目录，`config.yaml` 会写在这里。

## systemd 日志

安装脚本部署后：

```bash
sudo systemctl status sub2api
sudo journalctl -u sub2api -f
sudo systemctl restart sub2api
```

如果服务反复进入设置向导，优先检查实际 `DATA_DIR`、`config.yaml` 和 `.installed` 是否仍在同一个数据目录下。

## 仓库脚本

当前仓库根目录的 `scripts/` 下有一组用于 Windows 打包和 Linux 构建/运行的脚本。

### Windows 打包 Linux 源码包

```powershell
.\scripts\package-backend-source.bat
```

脚本会：

- 构建前端资源
- 复制后端源码、迁移、资源文件
- 复制 Linux 构建和服务脚本
- 生成 `output/sub2api-linux-src/`
- 生成 `output/sub2api-linux-src.zip`

Linux 侧解压后可运行：

```bash
sh ./scripts/build-linux-backend.sh
```

### Linux 构建运行包

```bash
sh ./scripts/build-linux-backend.sh
```

脚本会在 `output/sub2api-linux-bin/` 下生成：

- `sub2api`
- `config.example.yaml`
- `scripts/sub2api-service.sh`
- `scripts/cleanup-sub2api-logs.sh`
- `BUILD_INFO.txt`

同时生成归档：

```text
output/sub2api-linux-bin.tar.gz
```

### 简易服务脚本

```bash
./scripts/sub2api-service.sh start
./scripts/sub2api-service.sh status
./scripts/sub2api-service.sh restart
./scripts/sub2api-service.sh stop
```

默认值：

- `APP_BIN=../sub2api`
- `RUN_DIR=../run`
- `LOG_DIR=/data/logs/sub2api`
- `STOP_TIMEOUT=20`

日志按日期写入：

```text
/data/logs/sub2api/YYYY-MM-DD.log
```

### 清理历史日志

```bash
./scripts/cleanup-sub2api-logs.sh 7
```

参数表示保留最近多少天日志，默认保留 7 天。脚本只删除符合 `YYYY-MM-DD.log` 命名的旧日志文件。

## API Key 日用量巡检脚本

仓库中已有 `monitor/monitor.py`，用于查询 API Key 某天用量并按需发钉钉通知。

注意：

- 当前脚本是 Python 2 风格，需要 Python 2.7。
- 默认读取同目录 `apikey.txt`。
- 可通过 `--dry-run` 只打印，不发送通知。

Windows 示例：

```powershell
cd F:\Codes\GoCodes\sub2api\monitor
py -2 monitor.py --dry-run
```

Linux 示例：

```bash
cd /opt/sub2api-monitor
python2 monitor.py --dry-run --base-url "http://127.0.0.1:10888"
```

详细说明见仓库已有文档：`docs/MONITOR_CN.md`。

## 升级注意事项

升级时保留运行时数据目录：

- Docker：保留 `data/`、`postgres_data/`、`redis_data/` 或命名卷。
- systemd/二进制：保留实际 `DATA_DIR` 下的 `config.yaml` 和 `.installed`。
- 仅替换二进制时，不要覆盖运行时配置。

Docker 本地目录版升级：

```bash
docker compose -f docker-compose.local.yml pull
docker compose -f docker-compose.local.yml up -d
```

二进制替换后重启：

```bash
sudo systemctl restart sub2api
```
