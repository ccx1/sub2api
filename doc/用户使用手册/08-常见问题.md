# 常见问题

## 打开页面后为什么进入设置向导？

通常是运行数据目录不对，或者 `config.yaml` / `.installed` 不在当前运行数据目录中。

检查顺序：

1. 是否设置了 `DATA_DIR`。
2. Docker 是否挂载了 `/app/data`。
3. 当前工作目录是否和上次启动一致。
4. `config.yaml` 和 `.installed` 是否存在。

运行数据目录优先级是：

```text
DATA_DIR -> /app/data -> 当前工作目录
```

## 修改端口后为什么还是旧端口？

端口来自运行时配置和环境变量，不是编译进二进制的固定值。

排查：

- `SERVER_PORT` 环境变量是否覆盖了配置。
- 当前进程实际读取的是哪个 `config.yaml`。
- Docker Compose 的端口映射是否仍是旧值。
- systemd 服务文件里是否写了环境变量。

## API 返回 404 是什么原因？

先区分路径类型：

- 前端管理接口通常在 `/api/v1/...`
- 网关调用接口通常在 `/v1/...`、`/v1beta/...`、`/responses`、`/chat/completions`

如果是后台页面调用返回 404，优先检查前端 API 路径和后端路由是否匹配。

如果是网关调用返回 404，优先检查：

- Key 是否绑定了正确平台分组。
- 请求端点是否适合该平台。
- 图片接口是否只用于 OpenAI 分组。
- OpenAI 分组调用 `/v1/messages/count_tokens` 会返回不支持。

## API Key 为什么没有可复制的客户端配置？

常见原因：

- Key 没有分配分组。
- 用户没有该分组访问权限。
- 公开设置里的 API 基础地址没有配置，前端回退到当前站点地址。
- 分组平台和客户端类型不匹配。

先在用户端 Key 列表里确认分组列，再打开“使用密钥”。

## 用户看不到某个渠道或模型？

按下面顺序检查：

1. 渠道是否启用。
2. 渠道是否配置了平台和模型。
3. 分组是否绑定到渠道。
4. 用户是否能访问该分组。
5. 订阅分组是否过期。
6. 模型定价是否完整。

## Nginx 代理下 Codex 或粘性会话异常？

Nginx 默认可能丢弃带下划线的请求头。需要在 `http` 块开启：

```nginx
underscores_in_headers on;
```

修改后先测试配置，再 reload：

```bash
nginx -t
nginx -s reload
```

如果使用容器内 Nginx，请按实际容器名执行对应命令。

## Docker 重启后用户都被登出？

通常是 `JWT_SECRET` 没有固定。请在 `.env` 中设置固定值：

```env
JWT_SECRET=replace_with_random_hex
```

如果启用了 TOTP，也要固定：

```env
TOTP_ENCRYPTION_KEY=replace_with_random_hex
```

## 支付成功但余额没有到账？

先检查：

- 支付平台是否成功回调到 `/api/v1/payment/webhook/...`。
- 站点域名是否为 HTTPS。
- 防火墙或反向代理是否拦截回调。
- 服务商密钥和签名配置是否正确。
- 后台订单是否处于待处理、失败或已支付未发放状态。

管理员可在后台支付订单页查看订单详情，并按需重试发放。

## Claude Code Plan Mode 无法自动退出？

仓库 README 已记录该已知问题。临时处理方式是按 `Shift + Tab` 手动退出 Plan Mode，再输入内容告诉 Claude Code 同意或拒绝 Plan。

## 可以直接把文档里的示例模型名用于生产吗？

示例只说明配置格式。实际可用模型取决于：

- 上游账号权限
- 分组平台
- 渠道模型配置
- 后台模型定价
- 当前客户端支持情况

生产使用前，请以用户端“可用渠道”和后台账号测试结果为准。
