# 快速开始

Sub2API 是一个 AI API 网关平台。用户通过平台生成的 API Key 访问上游 AI 服务，系统负责鉴权、调度、计费、用量记录和管理后台展示。

## 部署方式选择

当前仓库提供三类常用部署方式：

| 方式 | 适合场景 | 特点 |
| --- | --- | --- |
| Docker Compose | 快速部署、生产自建、方便迁移 | 可同时拉起 Sub2API、PostgreSQL、Redis |
| Linux 安装脚本 | 裸机或 systemd 管理 | 安装二进制到服务器并创建 systemd 服务 |
| 源码编译 | 二次开发、本地调试、自定义构建 | 需要自行准备 Go、Node、PostgreSQL、Redis |

## 方式一：Docker Compose

推荐使用 `deploy/docker-deploy.sh` 生成本地目录版部署文件，数据目录更容易备份和迁移。

```bash
mkdir -p sub2api-deploy && cd sub2api-deploy
curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/docker-deploy.sh | bash
docker compose -f docker-compose.local.yml up -d
docker compose -f docker-compose.local.yml logs -f sub2api
```

脚本会生成 `.env`，并创建这些本地目录：

- `data/`：Sub2API 配置和应用数据
- `postgres_data/`：PostgreSQL 数据
- `redis_data/`：Redis 数据

如果 `ADMIN_PASSWORD` 留空，首次启动会自动生成管理员密码，需要从日志中查找：

```bash
docker compose -f docker-compose.local.yml logs sub2api | grep "admin password"
```

访问地址默认是：

```text
http://服务器IP:8080
```

## 方式二：Linux 安装脚本

脚本安装适合已经准备好 PostgreSQL 和 Redis 的 Linux 服务器。

```bash
curl -sSL https://raw.githubusercontent.com/Wei-Shaw/sub2api/main/deploy/install.sh | sudo bash
sudo systemctl start sub2api
sudo systemctl enable sub2api
```

然后在浏览器打开：

```text
http://服务器IP:8080
```

首次访问会进入设置向导，按页面提示填写数据库、Redis 和管理员账号。

常用命令：

```bash
sudo systemctl status sub2api
sudo journalctl -u sub2api -f
sudo systemctl restart sub2api
```

## 方式三：源码编译

源码编译适合开发或需要定制的场景。

前置条件：

- Go：以 `backend/go.mod` 为准
- Node.js 与 pnpm
- PostgreSQL
- Redis

构建命令：

```bash
cd frontend
pnpm install
pnpm run build

cd ../backend
go build -tags embed -o sub2api ./cmd/server
cp ../deploy/config.example.yaml ./config.yaml
./sub2api
```

`-tags embed` 会把前端构建产物嵌入后端二进制。没有这个参数时，二进制不包含完整前端页面。

## 运行数据目录

Sub2API 会按以下优先级寻找运行数据目录：

1. `DATA_DIR` 环境变量
2. `/app/data`，常见于 Docker 部署
3. 当前工作目录

`config.yaml` 和 `.installed` 都与这个数据目录有关。升级或替换二进制时，必须保留同一个数据目录，否则可能重新进入初始化流程或读取到错误配置。
