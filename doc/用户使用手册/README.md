## 角色说明

- 管理员：负责部署服务、初始化数据库和 Redis、创建上游账号、配置渠道/分组/定价/支付、查看用量和系统状态。
- 普通用户：负责注册或登录、创建 API Key、绑定可用分组、查看可用渠道和模型、复制客户端接入配置。

## 核心概念

- 上游账号：管理员添加的真实上游服务账号或 API Key。
- 分组：用于控制用户可访问的上游账号集合、平台类型、倍率、并发和访问限制。
- 渠道：用户侧可见的服务入口，聚合分组、平台和支持模型。
- API Key：用户在 Sub2API 生成的调用凭证，通常以 `sk-` 开头。
- 用量记录：网关记录的请求、Token、费用、端点等数据，可在用户端和管理后台查看。

## 重要约束

- 生产环境建议使用 HTTPS，并在反向代理层正确转发请求头。
- 使用 Nginx 代理并搭配 Codex CLI 时，需要在 `http` 块中启用 `underscores_in_headers on;`，否则带下划线的请求头可能被丢弃。
- 部署更新时要保留运行时数据目录，不要覆盖 `config.yaml` 和 `.installed`。
- Sora 相关配置在仓库 README 中标注为预留或暂不可用，本文档不把它作为可用能力介绍。
