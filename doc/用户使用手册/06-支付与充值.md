# 支付与充值

Sub2API 内置支付系统，用户可在前台自助充值，管理员在后台配置支付开关、支付服务商、套餐和订单处理。

更完整的支付参数说明见仓库已有文档：`docs/PAYMENT_CN.md`。

## 支持的支付方式

当前支付文档和路由中已有这些服务商：

| 服务商 | 支持方式 |
| --- | --- |
| EasyPay 易支付 | 支付宝、微信支付 |
| 支付宝官方 | 桌面扫码、移动端跳转 |
| 微信官方 | Native、H5、公众号/JSAPI |
| Stripe | 国际支付 |
| Airwallex | Webhook 路由已存在，具体可用性以后台服务商配置为准 |

## 开启流程

管理员进入：

```text
管理后台 -> 设置 -> 支付设置
```

基本流程：

1. 开启支付系统。
2. 设置金额范围、订单超时、最大待支付订单数。
3. 创建至少一个服务商实例。
4. 为前台可见的“支付宝”或“微信支付”按钮选择具体来源。
5. 配置套餐或允许余额充值。
6. 用小金额订单测试创建、支付、回调、入账。

## 用户充值流程

用户侧一般流程：

1. 登录前台。
2. 进入充值或订阅购买页面。
3. 选择金额、套餐和支付方式。
4. 创建订单。
5. 完成支付。
6. 系统收到回调后自动充值余额或开通订阅。

用户可查看自己的订单记录，订单异常时可联系管理员按订单号排查。

## Webhook 地址

支付回调地址格式如下，域名替换为自己的站点域名：

```text
https://your-domain.com/api/v1/payment/webhook/easypay
https://your-domain.com/api/v1/payment/webhook/alipay
https://your-domain.com/api/v1/payment/webhook/wxpay
https://your-domain.com/api/v1/payment/webhook/stripe
https://your-domain.com/api/v1/payment/webhook/airwallex
```

生产环境建议使用 HTTPS，并确保防火墙和反向代理允许支付平台回调。

## 订单管理

管理员可在后台支付订单页面执行：

- 查看订单列表和详情
- 取消订单
- 重试发放
- 处理退款
- 查看支付统计

支付配置、服务商实例和套餐都有管理接口，前端后台已对这些能力做了页面集成。

## 注意事项

- 支付密钥不要写入公开仓库。
- 回调必须能从公网访问。
- 多服务商实例时，注意每日限额和负载均衡策略。
- 官方支付和易支付可同时配置为后台实例，但前台同一个可见支付按钮需要选择唯一来源。
